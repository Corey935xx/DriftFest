# DriftFest website concept

A responsive, single-page promotional website for a fictional motorsport festival concept.

## Open locally

Open `index.html` in a modern browser. The site uses externally hosted photographs from Pexels and Google Fonts, so an internet connection is required for those assets to load.

## What's included

- Responsive desktop and mobile layouts
- Real motorsport photography from Pexels, with photographer/source credits in the footer
- Festival experience sections
- Filterable sample programme
- Example ticket tiers and a demo-only ticket selection interaction
- Venue concept section and FAQ

## Concept disclaimer

DriftFest is fictional. The date, venue setting, timetable, ticket types and prices are illustrative website content only. No event is taking place and no tickets are available.
